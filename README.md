# AR-DRIVE

AR-DRIVE is an internal company cloud file storage application for secure uploads, sharing, search, and collaboration.

## Phase 0 status

This repository is in the project initialization phase and includes the foundational frontend, backend, environment configuration, and development tooling required to continue with the next application phases.

## Structure

- frontend/ — React + Vite + TypeScript interface
- backend/ — Express + TypeScript API server
- docs/ — planning and documentation

## Commands

```bash
npm --prefix frontend install
npm --prefix backend install
npm run dev:frontend
npm run dev:backend
```

## Environment

Copy `.env.example` to `.env` and update the values for your local environment before running the application.
